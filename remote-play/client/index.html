Remote couch play

Create a private session or join with an invitation.

Keyboard: arrows, Z, X, A, S, Enter, left Shift, Escape and Tab. Standard gamepads map to these keys. Configure the same keys inside the emulator.

Sharing starts only after you choose a window. Guests can control only a host-approved game while that game is in the foreground. Close the FishBowl session to release controls.
