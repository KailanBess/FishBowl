# FishBowl for Windows

This folder contains the Windows edition of FishBowl only.

Open `FishBowl.exe` to use the hub. `FishBowl Setup.exe` installs the Windows app. The source files, artwork, installer scripts, and the optional LiveKit token-service template are included for development and packaging.

The Requirements Storage feature keeps user-provided BIOS, firmware, keys, and system archives in separate platform folders. It only organizes local files and never changes emulator configuration.

No Linux or Avalonia project files are included in this folder.
