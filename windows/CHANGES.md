## First startup popup animation mitigation

This covers Welcome, update notes, storage prompts and startup notifications. It does not change Windows-wide settings or the animation policy of the main window and other settings dialogs. Missing or unsupported DWM APIs leave the app functional.

## Installed main-content launch repair

FishBowl now follows the smallest numbered installed title metadata (.tmd) file to select its main content, matching Azahar's installed-title lookup. Without usable metadata, the fallback only accepts a matching executable NCCH with an extended header and ExeFS; manuals/data contents cannot be selected just because they share the program ID. A valid TMD whose main file is missing does not fall back to another content file. Compressed/wrapped TMD-selected files are left for the emulator to decode. Quoted {game} templates are normalized to prevent double-quoted paths. FishBowl's local launch log now records the emulator and command arguments for diagnosis.

20 installed-storage/content checks passed, including competing matching files, main-content metadata selection, missing main content, manual rejection, repeated launch, and quoted templates. The provided real Azahar log finds Pokemon X's program ID then fails with Error 1; it does not include the selected path. ## Game identification and icons

Adding a game detects its title, platform and title ID from available local metadata. Embedded title/icon support includes Nintendo DS banners, 3DS SMDH/NCCH/CIA metadata, Vita VPK metadata and installed Vita game data. PC executable metadata/icons and nearby PNG/ICO files are supported. GBA, Game Boy, N64 and raw GameCube/Wii disc headers provide names and IDs where available. Other formats fall back to a cleaned filename and extension; Switch filenames can supply their title ID. No online account, title database or decryption is used.

Detected icons are copied as PNG files into FishBowl's Artwork/GameIcons storage and retained across restarts. Custom names and existing valid artwork are preserved. Select an existing game and use **Game actions > Identify game and retain icon** to fill in its local metadata/icon. Emulator assignment is suggested only when exactly one configured emulator accepts the extension.

## Launching installed games

CIA packages assigned to Azahar/Citra/Lime3DS resolve to matching installed base-game NCCH content. Vita PKG/VPK packages assigned to Vita3K resolve to their installed title and use --run with the title ID. Configured/portable emulator storage is consulted. The installation package is not passed again on subsequent launches. The original package can be removed after identification and installation, while the stored icon and installed launch remain available.

If the matching installation cannot be found, FishBowl stops and explains how to install once inside the emulator or review its storage. It does not pretend installation succeeded. Update/DLC CIA files are not launched as base games. Explicit install flags in custom launch arguments require correction. Normal ROM, disc, PC and shortcut launch behavior remains available.

## Settings appearance

Secondary settings tabs use the same dark rounded header painter as Home, Library and Emulators. Settings pages and native text boxes share theme colors and consistent borders, including controls added after a dialog opens. Native text editing, caret, selection and scrollbars remain. Repeated appearance changes no longer compound inherited text size. The game editor has a separate action footer and usable multiline notes space.

## Run or install

Open FishBowl.exe to run, or FishBowl Setup.exe to install. Keep all six release files together. Close FishBowl before replacing an installed copy. Reinstalling replaces application files; keep your existing portable.flag and FishBowlData folder if present. Normal library storage is %LOCALAPPDATA%\FishBowl. Portable mode uses FishBowlData beside the application.
